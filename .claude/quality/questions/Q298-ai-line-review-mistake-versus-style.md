# Q298 · AI line review: what is a mistake and what is style? — **answered 2026-11-19: the keys decide**

Raised by: the same request as Q296. The owner: "we should have rules for
mistakes vs style … perhaps this could be compared to other outer lines of the
subject."

What it blocks: what the model is told counts as wrong, and what it must give
as evidence.

| | What it costs |
| --- | --- |
| **The keys decide** (recommended, **chosen**) | A feature is a mistake only if neither key has it at the matching place, and the model must name the key line it compared against. Anything both keys share is style. The subject's other outer lines — how its other joints meet — are supporting evidence, never proof on their own. |
| Keys plus a style note | A per-project note sent with every review. |
| Model judgement alone | Least predictable. |

A fix whose answer names no key line is refused by the engine, not trusted.

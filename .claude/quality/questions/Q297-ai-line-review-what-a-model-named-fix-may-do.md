# Q297 · AI line review: what may a model-named fix do? — **answered 2026-11-19: end edits, past a line width, previewed**

Raised by: the same request as Q296.

What it blocks: the verbs the review can ask the engine for, and whether the
cleaner's one-line-width bound (Q293) applies to them.

| | What it costs |
| --- | --- |
| **End edits, past a line width** (recommended, **chosen**) | Trim a named end back to where it meets, or passes closest to, another named line; join two named ends; remove a named mark. A trim may be longer than a line width — the knee overlap is ~70 px — but nothing is added and everything is previewed. |
| Same, keeping the width cap | Would not fix the knee. |
| Flag only | Marks suspected mistakes with a reason; the artist fixes them. |

The Q293 bound stays for the deterministic cleaner. A model-named fix is a
different thing: the artist sees the reason and the edit before it is written.

# Q164 · How much typography does the first text tool have? — **answered 2026-08-24: point text, and the three obvious next things are roadmapped**

| | What it costs |
| --- | --- |
| **Point text** (recommended, **chosen**) | Click, type. Family, size, weight and slant, tracking, leading, alignment; the colour from the current swatch; one style for the block. Enough for titles, signs, effects lettering and sprite labels — the type an animation actually contains. |
| Add box text | Also a dragged box with wrapping. Line breaking and re-flow are real work, and they need an answer for type that no longer fits. |
| Add text on a path | Also a baseline flowed along a drawn line. The most Lightbox-flavoured of the three, and it wants the placement/offset design settled first. |

The scope rule this is an application of: *how far do we go simulating a
medium — as far as the expression goes, and not one step further.* A title, a
sign painted on a door and a label on a sprite sheet are what type is for here;
a page of body copy is a different application.

Box text, text on a path and mixed styles within one block are each roadmapped
under *Guides and shapes*, so the next person picking one up finds it costed
rather than has to re-argue this.

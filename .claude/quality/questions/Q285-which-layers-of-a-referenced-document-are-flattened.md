# Q285 · Which layers of a referenced document are flattened? — **answered 2026-10-16: the visible ones, without the background**

Raised alongside Q284. A referenced document is flattened to one picture per
frame; the question is what goes into that picture.

| | What it costs |
| --- | --- |
| **Visible, minus background** (recommended, **chosen**) | What the source shows, without its opaque background — so the reference does not cover the paper it is taped over. Needs a rule for which layer *is* the background. |
| **Exactly as it shows** | Faithful, but an opaque frame covers the paper and every artist lowers the opacity to see anything. |
| **Pick layers at import** | Most control — *only the AnimSketch* — at the price of a dialog on every reference. Can be added later on top of the default without changing the record. |

**Why:** a reference sits *over the paper and under every drawing*. A
flattened frame that carries its own opaque paper turns into a wall at that
position in the stack. The source's hidden layers stay hidden for the same
reason the board shows a sheet view as it is set: the reference is what the
source's author is currently looking at.

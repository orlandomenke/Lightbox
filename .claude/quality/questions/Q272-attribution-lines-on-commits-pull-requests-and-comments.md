# Q272 · Attribution lines on commits, pull requests and comments — **answered 2026-10-14**

Raised 2026-10-14 by the owner ("there is a lot of co-authored or co-written
by in the code that can be removed"), after git-handler had flagged the
commit trailer more than once. Asked with the prompt.

Where the lines are: a `Co-Authored-By: Claude …` trailer in 1,721 of main's
2,775 commits; "🤖 Generated with Claude Code" at the end of about 290 merged
pull request descriptions; and `.claude/agents/git-handler.md` telling that
agent to end every comment it posts with "Generated by Claude Code". No source
file carries one.

| Decision | Chosen | What the alternatives cost |
| --- | --- | --- |
| **From now on** | **Stop all of them** (recommended) — one resident rule in `CLAUDE.md`, and the footer instruction removed from git-handler | Commit trailer only: pull requests and comments keep the footer. Nothing: they keep accumulating. |
| **The commits that already have one** | **Leave history as it is** (recommended) | A rewrite changes every commit id from the first trailer on and needs a force-push of the public `main`: every worktree, branch, salvage tag, fork and clone diverges, and every commit id cited in the ledgers, questions, design notes and pull request threads points at nothing. |
| **The pull request descriptions** | **Leave them** (recommended) | About 290 edits under the owner's account, each visible as an edit, for no change to the project. |

**Recommendation:** as marked, and the owner took all three.

## What follows from it, not up for preference

- **The rule is in `CLAUDE.md`, not only in memory**, because the harness
  reminds every session and subagent to add the lines; only a resident rule
  reaches all of them. The prelude ratchet is raised by its length
  (`.claude/quality/PRELUDE.md`).
- **Nothing already written is amended to remove one.** A commit made before
  the rule is pushed as it stands; rewriting it to drop a trailer is the history
  rewrite this decision declined, one commit at a time.
